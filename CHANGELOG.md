# Changelog

## 1.0.0 — Initial public preview

- Native macOS menu bar app with active and inactive states.
- Unlimited sessions and 30-minute, 1-hour, 2-hour, and 4-hour timers.
- Optional display sleep prevention.
- Saved duration and display preferences.
- Automatic release of power assertions on stop, expiry, and cleanup.
- English interface, source comments, and documentation.
- Native and universal build scripts, local tests, and a GitHub Actions workflow.

Distribution status: ad hoc signed; not notarized. Manual UI and Intel runtime
verification are still pending.
