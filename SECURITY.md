# Security and privacy

Eveille has no network code, accounts, analytics, automatic updates, or external
runtime dependencies. It stores only the duration and display preference in macOS
UserDefaults. It requests no administrator, Accessibility, screen recording, or
Full Disk Access permission.

Preventing display sleep can postpone automatic locking associated with display
sleep. Lock manually when needed. Eveille does not disable manual locking or alter
your password settings.

Do not post credentials, personal logs, or sensitive screenshots in public issues.
For a vulnerability, use GitHub's private vulnerability reporting if it is enabled.
Otherwise, open an issue asking the maintainer for a private reporting channel
without including exploit details or sensitive data.

Public preview binaries are ad hoc signed and have not been notarized by Apple.
The source and build scripts are available for inspection and local compilation.
