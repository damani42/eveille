# Eveille 1.0.0 — Public preview

A tiny native macOS menu bar app to keep your Mac awake during long tasks.

- One-click keep-awake control.
- Unlimited sessions or timers from 30 minutes to 4 hours.
- Optional display sleep prevention.
- Saved preferences and automatic assertion cleanup.
- English interface, offline operation, and no third-party dependencies.

Requires macOS 13 or later. The universal package contains Apple Silicon and Intel
executables. Runtime tests have passed on Apple Silicon; Intel execution, older
macOS versions, and manual interface verification are pending.

This preview is ad hoc signed and **not notarized**. macOS may block a downloaded
copy. Building from source is the recommended installation path for this preview.
The build does not bypass Gatekeeper or change system security settings.

Keep the laptop lid open. Other apps may still require your input or authorization.
